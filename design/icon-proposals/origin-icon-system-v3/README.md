# Origin icon set v2 - export

77 icons, one family: 24 x 24 grid, round caps and joins, outline. Single source of truth is
`design/icon-proposals/origin-icon-system-v2/generate_proposal.py`; this folder is generated by
`tools/mod-menu/generate_icons.py` then `tools/mod-menu/export_icons.py`. Do not hand-edit the files here.

## Folders

| Path | What |
|---|---|
| `svg/<name>.svg` | Final masters, 24 x 24 viewBox, stroke-based, `currentColor`. The weight class and optical-size scale are already applied (a `<g transform>` plus the class stroke width), so they look like the PNGs. |
| `png/<size>/<name>.png` | White on transparent, grid-fitted: strokes and dots snapped to whole pixels at that size, exact edge coverage. Sizes 24, 32, 44, 48, 64, 66, 88, 128. 44 / 66 / 88 are the mod-card sizes at GUI scale 2 / 3 / 4. At 24 px and below the small-size variant is used where an icon has one. Tint them with a colour multiply. |
| `atlas/` | The in-game atlases exactly as generated: `mod_icons.png` (192 px cells, 6 columns, 1152 x 2496), `mod_icons.json` (cell positions; ids and positions unchanged from main), `mod_icons_sdf.png` (exact distance field, range 16), `mod_icons_px/px_<N>.png` (one pixel-fitted atlas per physical size, 2280 KiB in total). |
| `contact-sheet.png` | Every icon at 44 and 88 px on Origin deepslate `#171C19`, enabled emerald `#5FD09B` beside disabled stone `#B8B5A6`, names underneath. |

## Weight classes

Three snapped stroke classes on the 24 grid, constant inside an icon, picked by centreline length
(long, dense drawings are thin; short, simple ones are bold) so the amount of ink is even across the set
(centreline length and ink area correlate at r = 0.94; the two length thresholds were searched for the
smallest ink spread). Rendered width is then snapped to whole pixels per size.

| Class | Stroke (grid units) | Rule |
|---|---|---|
| thin | 1.65 | centreline length >= 86 |
| regular | 1.9 | 66 to 86 |
| bold | 2.2 (the pack's own weight) | < 66 |
| brand | 1.55 | the Origin mark keeps its brand stroke |

Two overrides on top: an icon is stepped one class thinner when its details merge at 22/33/44/66/88 px,
and side-by-side icons share the thinnest class of the group (the eight title-menu icons; general /
HUD editor / performance / backing; clock / stopwatch / day counter; armor / potion HUD; team view /
discord / hypixel / bed wars). Will's 1.25 / 1.55 / 1.7 were measured on v1, whose 1.55 stroke the
shader thickened by 0.6; on v2's 2.2 base the same ratios are 1.65 / 1.9 / 2.2.

Counts: thin 45, regular 7, bold 24, brand 1.

## Checks

Generator audit at (22, 33, 44, 66, 88) px: 0 problem(s), 9 informational (10 - 14 px sizes), 431 icon x size cells.

The audit renders every icon through the real pixel path at 22, 33, 44, 66 and 88 px and compares it with a
high-resolution reference: 0 isolated pixels, no merged strokes, no closed counters, no split strokes.
Small suns (full bright, time changer, weather) are also held to 1.5 grid units of clear air between rays and disc.
Not covered by the hard gate: the 10 - 14 px sizes (GUI scale 1 only) of the title icons, search and server address,
where a few strokes still merge; they are listed as INFO by the generator.
