Origin Mod Menu

Every direction below has to sit next to this without a seam. Its identity, read from OriginModMenuScreen, OriginDeck and OriginTheme (1.21.1):

Palette
"Workbench": panel #141816, card #1D2320, parchment text #F1E9D2, emerald #5FD09B, red #D9675A, gold #E9C46A
Type
Inter 400/600 through MSDF; tabs and pills in tracked uppercase
Shape
SDF rounded panels, radii 1 / 2 / 3 GUI px; 920 x 580 window
Parts
Five tabs (Mods, Settings, Waypoints, Cosmetics, Friends), Edit HUD, filter pills, four-column card grid with line icons, Options and Enabled/Disabled pills
Reached by
Title "Mods" button (direct) and Right Shift, then HUD editor, then Mods
